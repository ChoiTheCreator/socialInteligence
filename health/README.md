## 데이터셋

- 출처: 보건복지부 지역사회건강조사(Community Health Survey, CHS)
- 기간: 2015 ~ 2025 (연간, 11개년)
- 표본: 연간 약 22만 8천 ~ 23만 1천명, 총 약 250만건
- 지역: 전국 17개 시도 (서울·부산·대구·인천·광주·대전·울산·세종·경기·강원·충북·충남·전북·전남·경북·경남·제주)
- 원본 파일: `data/chs15_all.csv` ~ `data/chs25_all.csv`

### 주요 변수

| 변수 코드     | 설명                  | 유효 범위                     | 파생 변수              |
| ------------- | --------------------- | ----------------------------- | ---------------------- |
| `qoa_01z1`    | 주관적 건강상태       | 1(매우좋음)~5(매우나쁨)       | 4 이상 → 건강나쁨=1    |
| `mtb_01z1`    | 우울증상 경험         | 1(있음), 2(없음)              | 1 → 우울증상=1         |
| `ira_01z1`    | 미충족의료 경험       | 1(있음), 2(없음)              | 1 → 미충족의료=1       |
| `sca_01z1`    | 이웃 신뢰(사회적자본) | 1(신뢰), 2(불신)              | 1 → 사회적신뢰=1       |
| `mta_01z1`    | 스트레스 인지         | 1(대단히많이)~4(거의없음)     | 1~2 → 스트레스\_많음=1 |
| `ctprvn_code` | 지역코드              | 11·26·27·28·29·30·31 → 광역시 | 나머지 → 도·군         |

결측 처리: 7(모름)/8(비해당)/9(무응답) 및 유효범위 초과값 → NaN

## 전처리 상세 (`EDA/eda_chs_2015_2025.ipynb` 섹션 1~3)

### 1단계: 데이터 로딩 및 컬럼 표준화

**처리 내용**

연도별 CSV 파일(chs15~chs25) 11개를 개별 로딩 후 필요 컬럼만 선택(`keep`)해 병합.
모든 컬럼명을 소문자로 일괄 변환.

```python
df.columns = df.columns.str.lower()
keep = ['year', 'age', 'sex', 'region'] + [c for c in COMMON_HEALTH_VARS if c in df.columns]
```

**이유**
- 연도별 CHS 파일의 컬럼명 대소문자가 혼재되어 있어 `df['QOA_01z1']`과 `df['qoa_01z1']`가 달라 오류 발생 가능
- 전체 컬럼을 유지하면 파일당 수백 개의 컬럼이 있어 메모리 과부하. 분석에 필요한 변수만 선택해 효율화

---

### 2단계: 연도 컬럼 통일

**처리 내용**

연도 컬럼명이 연도별로 다름. 우선순위 순서로 탐색 후 `year`로 통일.

| 연도 | 원본 컬럼명 |
|------|------------|
| 2015~2017 | `josa_year` |
| 2018~2022 | `examin_year` |
| 2023+ | `examin_code` |

컬럼이 없으면 파일명에서 추출한 연도를 직접 할당.

**이유**
- 조사 설계 변경에 따라 같은 정보가 다른 컬럼명으로 저장됨. 통일하지 않으면 `groupby('year')` 등 연도별 집계 불가

---

### 3단계: 지역코드 통일

**처리 내용**

2015~2018년 파일은 `city_cd` 컬럼에 알파벳 코드(A~Q)를 사용. 2019년 이후는 `ctprvn_code`에 숫자 코드 사용.

```python
CITY_TO_CODE = {
    'A':11, 'B':26, 'C':27, 'D':28, 'E':29, 'F':30, 'G':31,  # 7개 광역시
    'H':36,                                                      # 세종
    'I':41, 'J':42, 'K':43, 'L':44, 'M':45,                   # 경기~전북
    'N':46, 'O':47, 'P':48, 'Q':50                             # 전남~제주
}
if 'city_cd' in df.columns:
    df['region'] = df['city_cd'].map(CITY_TO_CODE)
elif 'ctprvn_code' in df.columns:
    df.rename(columns={'ctprvn_code': 'region'}, inplace=True)
```

**이유**
- 코드 체계가 달라 단순 병합 시 지역 정보가 섞임 (알파벳 A와 숫자 11이 동일 지역인지 알 수 없음)
- 숫자 코드로 통일해야 2015~2025 전 기간 지역별 분석 가능
- 단, 알파벳→숫자 매핑 시 순서가 시도별 공식 코드와 일치하는지 코드북 교차 확인 필요 (지역별 분석은 코드가 명확한 2019+ 우선)

---

### 4단계: 결측 코드 처리 (유효범위 필터링)

**처리 내용**

CHS 코드북은 `7=모름`, `8=비해당`, `9=무응답`, `77/88/99`, `888/999` 등을 결측으로 정의. 변수별 유효 범위를 지정해 범위 밖 값은 NaN으로 대체.

```python
VAR_VALID_RANGE = {
    'qoa_01z1': (1, 5),   # 주관적 건강
    'mta_01z1': (1, 4),   # 스트레스
    'mtb_01z1': (1, 2),   # 우울증상
    'sca_01z1': (1, 2),   # 사회적자본
    'ira_01z1': (1, 2),   # 미충족의료
    'obb_01z1': (1, 4),   # 비만도
    'hya_19z1': (1, 2),   # 고혈압
    'dia_04z1': (1, 2),   # 당뇨
    'pha_04z1': (0, 7),   # 걷기일수/주
    # PHQ-9 9개 항목: (1, 3)
    ...
}
df[col] = df[col].where((df[col] >= vmin) & (df[col] <= vmax))
```

**이유**
- `9`(무응답)을 그대로 두면 `mta_01z1`의 경우 4점 척도에서 9점이 최고 스트레스로 잘못 집계됨
- `8`(비해당)이 섞이면 스트레스 평균이 실제보다 2배 가까이 부풀어오름
- 단순 listwise deletion 대신 유효범위 기준으로 처리해 다른 컬럼 정보를 최대한 보존 (변수별 독립 NaN 처리)
- `pd.to_numeric(errors='coerce')`를 선행해 문자열로 저장된 숫자도 처리

**결측률 현황 (처리 후, 대략적 수치)**

| 변수 | 결측률 (대략) |
|------|-------------|
| `qoa_01z1` (건강나쁨) | ~1~2% |
| `mtb_01z1` (우울증상) | ~1~3% |
| `ira_01z1` (미충족의료) | ~1~2% |
| `sca_01z1` (사회적신뢰) | ~2~4% |
| `hya_19z1` (고혈압, 2019+) | ~3~5% |
| PHQ-9 항목 | ~5~10% |

### 5단계: 두 개 데이터프레임 분리 운영 (df_all / df_new)

**처리 내용**

- `df_all`: 2015~2025 전체, 11개 공통 변수만 포함 (약 250만 행)
- `df_new`: 2019~2025만, 만성질환·PHQ-9·걷기 등 추가 변수 포함 (약 160만 행)

**이유**
- 고혈압(`hya_19z1`), 당뇨(`dia_04z1`), 뇌졸중, 관절염, PHQ-9 등은 2019년 이후 조사에만 존재
- 이 변수들을 2015~2018 데이터에 강제 병합하면 해당 연도의 결측이 100%가 되어 분석 불가
- 연도 트렌드 분석(2015~2025)은 `df_all`, 만성질환 및 PHQ-9 분석은 `df_new` 사용으로 역할 분리

### 6단계: 이진 건강지표 파생

**처리 내용**

원시 척도 변수를 임상적 기준에 따라 0/1 이진 변수로 변환. `.astype(float).where(원본.notna())`로 NaN 보존.

| 파생변수 | 조건 | 원시 변수 | 이유 |
|---------|------|---------|------|
| `건강나쁨` | `qoa_01z1 >= 4` | 5점 척도 | 4=나쁨, 5=매우나쁨. 상위 2개 범주를 "나쁨"으로 묶음 |
| `우울증상` | `mtb_01z1 == 1` | 1=있음, 2=없음 | 코드북 기준 직접 매핑 |
| `미충족의료` | `ira_01z1 == 1` | 1=있음, 2=없음 | 코드북 기준 직접 매핑 |
| `사회적신뢰` | `sca_01z1 == 1` | 1=신뢰, 2=불신 | 코드북 기준 직접 매핑 |
| `스트레스_많음` | `mta_01z1 <= 2` | 4점 척도(1=대단히~4=거의없음) | 1=대단히, 2=많이를 "많음"으로 묶음 |
| `비만` | `obb_01z1 == 4` | 4단계 비만도 | 4=비만에 해당하는 코드 |
| `고혈압` | `hya_19z1 == 2` | 1=없음, 2=있음 | 2019+ 변수, 코드가 직관에 반대이므로 주의 |
| `당뇨` | `dia_04z1 == 1` | 1=있음, 2=없음 | 코드북 기준 (고혈압과 코딩 방향 반대) |

**이유**
- 척도형 변수를 이진화하면 집단 간 비율 비교, 카이제곱 검정, 로지스틱 회귀가 용이해짐
- 리커트 척도를 연속형으로 취급하면 산술 평균의 해석이 불명확 (3.2점이 "나쁨"인지 알기 어려움)
- 고혈압의 경우 `hya_19z1`가 `1=없음, 2=있음`으로 코딩되어 있어 `==2`가 유병을 의미함에 주의

### 7단계: PHQ-9 총점 계산 (2019+ 한정)

**처리 내용**

우울증상 선별도구 PHQ-9의 9개 문항(`mtb_07a1`~`mtb_07i1`)을 합산.
CHS에서는 각 문항을 1~3으로 코딩하므로 0 기저로 변환(−1) 후 합산 → 0~18점.

```python
phq_cols = ['mtb_07a1', 'mtb_07b1', ..., 'mtb_07i1']
df_new['PHQ9_총점'] = (df_new[phq_cols] - 1).sum(axis=1)
df_new['PHQ9_총점'] = df_new['PHQ9_총점'].where(df_new[phq_cols].notna().all(axis=1))
df_new['우울위험'] = (df_new['PHQ9_총점'] >= 10).astype(float)
```

**이유**
- 단일 문항 `mtb_01z1`(우울증상 경험 여부)은 자기보고 단순 질문으로 임상적 우울과 거리가 있음
- PHQ-9 10점 이상은 중등도 우울(moderate depression) 기준으로 임상적으로 검증된 컷오프
- 9개 항목 중 하나라도 결측이면 총점을 NaN으로 처리 (부분 합산은 점수 왜곡 위험)

---

### 8단계: 흡연 통합 변수 (연도별 문항 변경 대응)

**처리 내용**

흡연 관련 문항이 2023년에 변경됨.

| 연도 | 원시 변수 | 코딩 방식 |
|------|---------|---------|
| 2019~2022 | `sma_01z1` | 1=매일흡연, 2=가끔, 3=과거흡연, NaN(8=비해당)=비흡연 |
| 2023+ | `smf_01z1` | 1=흡연경험있음, 2=없음 |

```python
# 2019-2022: sma_01z1이 NaN이 아니면 흡연(비해당=비흡연으로 해석)
df_new.loc[mask19_22, '흡연'] = df_new.loc[mask19_22, 'sma_01z1'].notna().astype(float)
# 2023+: smf_01z1 == 1이면 흡연
df_new.loc[mask23, '흡연'] = (df_new.loc[mask23, 'smf_01z1'] == 1).astype(float)
```

**이유**
- 2023년 조사 설계 변경으로 흡연 문항이 달라져 단순 병합 불가
- 연도 간 비교 가능한 통합 변수를 만들기 위해 기간별 로직 분리 적용
- 단, 2019-2022의 `sma_01z1 NaN = 비흡연` 해석은 "비해당=비흡연" 코드북 가정에 의존하므로 해석 시 명시 필요

### 9단계: 나이 그룹화

**처리 내용**

```python
age_bins   = [18, 29, 39, 49, 59, 69, 120]
age_labels = ['19-29세', '30-39세', '40-49세', '50-59세', '60-69세', '70세이상']
df_all['age_group'] = pd.cut(df_all['age'], bins=age_bins, labels=age_labels)
```

**이유**
- CHS는 만 19세 이상만 조사 대상. 18세 미만 데이터가 포함되지 않도록 하한을 18로 설정
- 10년 단위 구간은 정책·임상에서 표준적으로 사용되는 기준
- 70세 이상을 하나로 묶은 이유: 표본 충분성 및 "노년기 이후" 구분이 분석 목적에 맞음
- `pd.cut`으로 연속형 나이를 범주형으로 변환, 이후 `groupby('age_group')` 집계 가능

### 주요 발견사항

**도시-농촌 격차**

- 도·군 지역이 광역시보다 건강나쁨률·미충족의료율·스트레스률 모두 높음
- 지역유형별 지표 비교: 도·군 > 광역시 (방향 일관)
- 지역 건강취약 종합지수(건강나쁨+미충족의료+스트레스+우울+비만 정규화 평균): 도·군 지역이 상위권 다수 차지

**의료 접근성 × 건강결과**

- 지역별 미충족의료율 vs 건강나쁨율: 양의 선형 패턴 (Pearson r 양수 방향)
- 미충족의료율 vs 우울증상율: 동일 방향의 연관 관찰
- 농촌 지역 의료 자원 부족이 건강결과 악화와 동반하는 구조

**COVID-19 전후 격차 변화**

- 코로나 전(2017-2019) vs 코로나 후(2021-2023): 지역별 건강나쁨률 표준편차 소폭 변화
- 우울증상률은 코로나 시기(2020-2021)에 전반적으로 상승 후 일부 회복
- 지역별 격차 방향성: 일부 지역 악화, 일부 지역 개선 (혼재)

**사회적 자본 × 정신건강**

- 사회적자본(이웃 신뢰) 높음 → 우울증상률 낮음 (음의 방향 연관)
- 사회적신뢰율 vs 우울증상율 지역 산점도에서 음의 기울기 확인
- 나이그룹별 분석에서도 신뢰높음 집단이 일관되게 낮은 우울증상률

**연도별 트렌드 (2015-2025)**

- 건강나쁨률: 2015년 대비 완만한 감소 경향
- 우울증상률: COVID-19 시기 일시 상승 후 회복
- 미충족의료율: 2020년 이후 감소 추세
- 비만율: 지속 증가 경향

**나이별 패턴**

- 건강나쁨, 고혈압, 당뇨, 뇌졸중, 관절염: 70세 이상이 19-29세 대비 현저히 높음
- 우울증상, 스트레스: 나이 역할이 비선형 (중년층에서도 높음)
- 나이격차(70세이상 - 19-29세): 건강나쁨 약 +35~40%p, 고혈압 약 +45~50%p

**성별 차이**

- 우울증상, 스트레스: 여성이 남성보다 높음 (격차 약 3~5%p)
- 비만, 음주: 남성이 높음
- 만성질환: 고혈압·당뇨 유병률은 남성 우세, 골다공증·관절염은 여성 우세

## 가설 검정 (`HypothesisTesting/HypothesisTesting_Health_Inequality.ipynb`)

### 검정 원칙

- 유의수준: α = 0.05
- 검정 전 가정 확인 필수: 정규성(Shapiro-Wilk) → 가정 충족 여부에 따라 모수/비모수 선택
- 개인 수준 이분결과: 카이제곱 + Cramér's V (효과크기)
- 지역 수준 소표본(n=16): Mann-Whitney U + rank-biserial r
- 상관분석: 정규성 충족 시 Pearson, 위반 시 Spearman

---

### H1: 도시-농촌 건강 격차

**가설**

- H0: 광역시와 도·군 간 건강나쁨률·미충족의료율에 차이가 없다
- H1: 도·군이 광역시보다 건강나쁨률·미충족의료율이 유의하게 높다 (단측)

**가정 확인**

| 가정             | 검정 방법            | 대상                            | 결과                                             |
| ---------------- | -------------------- | ------------------------------- | ------------------------------------------------ |
| 기대빈도 > 5     | 교차표 기대빈도 산출 | 개인 수준 (수백만 명)           | 충족 (수십만 이상)                               |
| 지역 수준 정규성 | Shapiro-Wilk         | 광역시 7개, 도·군 9개 지역 비율 | 소표본(n<10)으로 검정력 약함 → Mann-Whitney 적용 |
| 등분산성         | Levene's test        | 광역시 vs 도·군                 | 참고용으로 실시                                  |

**검정 방법 및 효과크기**

| 수준 | 검정                                 | 효과크기 지표   |
| ---- | ------------------------------------ | --------------- |
| 개인 | 카이제곱 (chi2_contingency)          | Cramér's V      |
| 지역 | Mann-Whitney U (단측: rural > metro) | Rank-biserial r |

**결론**: 개인·지역 수준 모두에서 도·군이 광역시보다 건강나쁨률과 미충족의료율이 통계적으로 유의하게 높음. H1 지지.

---

### H2: 의료 접근성과 건강결과

**가설**

- H0: 지역별 미충족의료율과 건강나쁨률·우울증상률 간 상관관계가 없다
- H1: 미충족의료율이 높은 지역일수록 건강나쁨률·우울증상률이 유의하게 높다 (양의 방향)

**가정 확인**

| 가정   | 검정 방법                | 결과                                                       |
| ------ | ------------------------ | ---------------------------------------------------------- |
| 정규성 | Shapiro-Wilk (n=16 지역) | 소표본으로 검정력 제한 → 결과에 따라 Pearson/Spearman 선택 |
| 선형성 | Q-Q Plot 시각적 확인     | 시각화로 판단                                              |

**검정 방법**

- Shapiro-Wilk p ≥ 0.05: Pearson 상관계수
- Shapiro-Wilk p < 0.05: Spearman 순위상관계수

**결론**: 지역 수준 상관분석에서 미충족의료율과 건강결과 간 양의 연관 방향 확인. 단, n=16으로 검정력이 낮아 통계적 유의성 결과를 회귀분석에서 보완.

---

### H3: COVID-19 이후 지역 건강격차 변화

**가설**

- H0: COVID-19 전후 지역 간 건강나쁨률 분산에 차이가 없다
- H1: COVID-19 이후 지역 간 건강격차(표준편차)가 소폭 감소했다 (단측)

**가정 확인**

| 가정          | 검정 방법     | 대상                                                     |
| ------------- | ------------- | -------------------------------------------------------- |
| 정규성        | Shapiro-Wilk  | 전기(2017-2019), 후기(2021-2023) 각 16개 지역 건강나쁨률 |
| 등분산성 비교 | Levene's test | 두 기간 분포 간 분산 동질성                              |

**검정 방법**

- Levene's test: 두 기간 분포의 분산 차이 검정
- F-test (분산비): var(전기) / var(후기) — 단측 (감소 방향)
- 연도별 표준편차 시계열: 추이를 시각화로 보완

**결론**: 절대적 표준편차 변화량과 방향성은 확인되나, 통계적 유의성은 소표본(n=16) 한계로 신중한 해석 필요. 연도별 표준편차 추이 시각화를 함께 제시.

---

### H4: 사회적 자본과 정신건강

**가설**

- H0: 이웃 신뢰도(사회적자본)와 우울증상 경험 간 연관이 없다
- H1: 사회적 신뢰도가 높을수록 우울증상률이 유의하게 낮다 (음의 방향)

**가정 확인**

| 가정             | 검정 방법       | 대상                           | 결과                      |
| ---------------- | --------------- | ------------------------------ | ------------------------- |
| 기대빈도 > 5     | 교차표 기대빈도 | 개인 수준                      | 충족                      |
| 지역 수준 정규성 | Shapiro-Wilk    | 16개 지역 신뢰율 및 우울증상율 | 결과에 따라 Spearman 적용 |

**검정 방법 및 효과크기**

| 수준 | 검정                                 | 효과크기     |
| ---- | ------------------------------------ | ------------ |
| 개인 | 카이제곱 (신뢰여부 × 우울증상)       | Cramér's V   |
| 지역 | Spearman 상관 (신뢰율 vs 우울증상율) | Spearman rho |

**결론**: 개인 수준에서 사회적 신뢰 높음 집단이 우울증상률이 유의하게 낮음. 지역 수준에서도 음의 연관 방향 관찰. H1 지지.

---

### 종합 가설 검정 결과

| 가설               | 검정 방법                             | 효과크기                    | 결론                        |
| ------------------ | ------------------------------------- | --------------------------- | --------------------------- |
| H1 도시-농촌 격차  | 카이제곱(개인) + Mann-Whitney U(지역) | Cramér's V, rank-biserial r | 지지                        |
| H2 의료 접근성     | Pearson/Spearman 상관 (지역, n=16)    | r 또는 rho                  | 방향 지지, 검정력 제한      |
| H3 COVID 격차 완화 | Levene + F-test (분산비)              | SD 변화량                   | 방향 관찰, 유의성 신중 해석 |
| H4 사회적 자본     | 카이제곱(개인) + Spearman(지역)       | Cramér's V, rho             | 지지                        |

공통 한계: 지역 수준 분석은 n=16으로 검정력 낮음. 개인 수준 대규모 표본은 p값이 과도하게 유의해질 수 있으므로 효과크기 중심 해석 권장.

## 회귀분석 (`Regression/Regression_Health_Inequality.ipynb`)

### 분석 설계

| 모델 | 종속변수            | 독립변수                                          | 분석 수준            | 방법          |
| ---- | ------------------- | ------------------------------------------------- | -------------------- | ------------- |
| M1   | 지역 건강나쁨율     | 미충족의료율                                      | 지역 (n=16)          | 단순 OLS      |
| M2   | 지역 우울증상율     | 사회적신뢰율                                      | 지역 (n=16)          | 단순 OLS      |
| M3   | 지역 건강나쁨율     | 미충족의료율 + 사회적신뢰율 + 도농더미 + 고령자율 | 지역 (n=16)          | 다중 OLS      |
| M4   | 개인 건강나쁨 (0/1) | 미충족의료 + 사회적신뢰 + 우울증상 + 도농더미     | 개인 (10% 층화 샘플) | 로지스틱 회귀 |

### 회귀 가정 검증 체계

모든 모델에 대해 아래 순서로 가정 검증 실시:

**1. 선형성**

- 산점도 + LOWESS 비선형 곡선 비교 (M1, M2)
- 독립변수-종속변수 간 선형 관계 시각적 확인

**2. 잔차 정규성**

- Jarque-Bera 검정 (H0: 잔차가 정규분포를 따름)
- 잔차 Q-Q Plot 시각화
- 잔차 히스토그램

**3. 등분산성 (Homoscedasticity)**

- Breusch-Pagan 검정 (H0: 잔차 분산이 일정)
- 잔차 vs 예측값 산점도
- 스케일-위치 플롯 (Scale-Location Plot)

**4. 다중공선성** (M3 한정)

- VIF (Variance Inflation Factor): VIF < 5 권장, VIF > 10 심각
- 독립변수 간 상관행렬 히트맵

---

### M1: 미충족의료율 → 건강나쁨율 (단순 OLS)

**이론적 근거**: 의료 접근성 저하 → 질병 조기발견·치료 지연 → 주관적 건강 인식 악화

**가정 확인**

- 선형성: 산점도 + LOWESS로 선형 패턴 시각 확인
- 잔차 정규성: Jarque-Bera 검정 실시 (소표본으로 위반 가능성 있음)
- 등분산성: Breusch-Pagan 검정 실시

**결과 해석 포인트**

- 기울기 β1 부호: 양수(+) 예상 (미충족↑ → 건강나쁨↑)
- n=16으로 R² 및 p값 해석 시 신뢰구간 폭 반드시 병기
- 단순 OLS는 교락변수 미통제 → M3에서 보완

---

### M2: 사회적신뢰율 → 우울증상율 (단순 OLS)

**이론적 근거**: 사회적 자본(신뢰) → 스트레스 완충, 사회적 지지 강화 → 정신건강 개선

**가정 확인**

- 선형성: 산점도 + 추세선
- 잔차 정규성: Jarque-Bera
- 등분산성: Breusch-Pagan
- 4패널 잔차 진단 차트

**결과 해석 포인트**

- 기울기 β1 부호: 음수(-) 예상 (신뢰율↑ → 우울증상율↓)
- 단순 OLS이므로 개인 수준 특성(나이, 성별) 미통제

---

### M3: 다중 OLS — 건강나쁨율의 복합 결정 요인

**독립변수**

- 미충족의료율: 의료 접근성
- 사회적신뢰율: 사회적 자본
- 도농\_더미 (도·군=1, 광역시=0): 지역유형
- 고령자율 (65세 이상 비율): 인구 구조 통제

**가정 확인**

- VIF 다중공선성: 4개 변수 모두 VIF < 10 여부 확인
- 독립변수 간 상관행렬 히트맵
- 잔차 정규성 (Jarque-Bera)
- 등분산성 (Breusch-Pagan)
- 4패널 잔차 진단 (잔차 vs 예측값, Q-Q, 스케일-위치, 실제 vs 예측)

**결과 해석 포인트**

- 고령자율 통제 후에도 도농더미 유의: 인구 구조 이외의 순수 지역 격차 확인 가능
- 각 변수의 독립적 기여도 (partial effect) 분리
- Adjusted R²: 설명되지 않은 분산의 비율 → 추가 설명변수 필요성 판단

---

### M4: 개인 수준 로지스틱 회귀

**목적**: 지역 수준(n=16) 분석의 한계를 보완, 수백만 개인 데이터 활용

**독립변수**: 미충족의료 (0/1), 사회적신뢰 (0/1), 우울증상 (0/1), 도농\_더미 (0/1)

**표본**: 전체의 10% 층화 샘플링 (계산 속도, 재현 가능성)

**가정 확인**

- 다중공선성: VIF 확인 (4개 이진 변수)
- 선형성 (log-odds): 이진 독립변수이므로 별도 확인 생략

**결과 해석 포인트**

- OR (Odds Ratio) > 1: 건강나쁨 위험 증가
- OR < 1: 건강나쁨 위험 감소
- 95% CI가 1을 포함하면 통계적으로 유의하지 않음
- 초대규모 표본으로 미미한 효과도 유의하게 나옴 → OR 크기와 CI 폭 중심 해석
- McFadden R²: 로지스틱 모델 전체 설명력 (0.2 이상이면 양호)

---

### 회귀분석 공통 한계

1. 지역 수준 모델(M1~M3): n=16으로 통계적 검정력 낮음 — 방향성(부호)과 95% 신뢰구간 해석이 p값보다 중요
2. 생태학적 오류(ecological fallacy): 지역 수준 결과를 개인에 직접 적용 불가
3. 횡단면 데이터: 인과관계 주장 불가, 연관성만 확인
4. 개인 수준 모델(M4): 초대규모 표본으로 작은 OR도 유의 → 실질적 효과 크기 판단 필요
5. 미통제 교락변수: 소득, 교육, 직업 등 사회경제적 변수 부재

- 도·군 지역은 광역시에 비해 다차원적으로 건강 취약 (건강나쁨, 미충족의료, 우울증상 모두 높음)
- 의료 접근성 부족은 건강결과 악화와 동반하며, 단순 연관을 넘어 정책 개입의 우선 타깃
- 사회적 자본(이웃 신뢰)은 정신건강의 보호 요인으로 작용 — 지역 공동체 강화가 건강 증진 수단이 될 수 있음
- COVID-19 이후 지역별 격차 방향은 혼재 (일부 악화, 일부 개선) — 단일 추세로 단정 짓기 어려움
- 분석 전반에 걸쳐 소표본(n=16 지역) 한계가 반복적으로 등장 — 시군구 단위 세분화 또는 패널 분석을 추후 과제로 제안
