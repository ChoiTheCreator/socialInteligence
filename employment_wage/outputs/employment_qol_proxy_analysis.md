# 고용 키워드 기반 삶의 질 proxy 비교

## 1. 분석 전제
현재 데이터에는 실제 삶의 만족도 값이 없다. 따라서 이 문서는 실제 삶의 질을 직접 측정하지 않고, 현재 보유한 고용 키워드로 `고용 여건 관점의 삶의 질 proxy`를 비교한다.

이 proxy는 탐색용이다. 변수 방향과 가중치를 공개하고, 결과를 삶의 만족도 자체로 해석하지 않는다.

## 2. 사용한 변수와 방향

| 변수 | 방향 | 해석 주의 |
|---|---|---|
| 여성 취업자 비중 | 높을수록 유리 | 고용률이 아니라 취업자 구성비다. 여성 노동시장 참여의 proxy로만 해석한다. |
| 남녀 취업자 구성비 격차 | 낮을수록 유리 | 고용률 격차가 아니라 취업자 구성비 격차다. |
| 청년층 취업자 비중 | 높을수록 유리 | 청년 고용률이 아니라 취업자 중 청년층 비중이다. 지역 연령구조 영향을 받는다. |
| 임금근로자 비중 | 높을수록 유리 | 임금근로자 비중을 안정성 proxy로 사용한다. 일자리 질 전체를 대표하지는 않는다. |
| 임시근로자 비율 | 낮을수록 유리 | 전체 취업자 대비 임시근로자 비율이다. |
| 일용근로자 비율 | 낮을수록 유리 | 전체 취업자 대비 일용근로자 비율이다. |
| 자영업자 비율 | 낮을수록 유리 | 자영업이 항상 낮은 삶의 질을 의미하지는 않는다. 불안정성 proxy로만 제한 해석한다. |
| 단시간 취업자 비율 | 낮을수록 유리 | 단시간 근로는 자발적 선택일 수도 있다. 불완전취업 가능성 proxy로만 해석한다. |
| 장시간 취업자 비율 | 낮을수록 유리 | 장시간 노동 부담 proxy로 해석한다. |

## 3. 수도권 vs 비수도권 결과

- 수도권 평균 proxy 점수: 62.72
- 비수도권 평균 proxy 점수: 47.26
- 격차(수도권 - 비수도권): 15.47

현재 고용 구조 proxy 기준으로는 수도권이 비수도권보다 유리하게 관찰된다.

## 6. 결론
현재 보유한 고용 키워드만 놓고 보면, 수도권은 청년층 취업자 비중과 임금근로자 비중에서 유리하고, 비수도권은 고령층 취업자 비중·자영업자 비율·단시간 취업자 비중이 높게 관찰된다.

다만 이 결과는 실제 삶의 만족도 비교가 아니다. 삶의 만족도 원자료가 들어와야 `고용 여건이 삶의 만족도 격차와 관련되는지`를 검증할 수 있다.
