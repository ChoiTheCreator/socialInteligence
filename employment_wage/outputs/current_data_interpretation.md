# 현재 데이터 기준 EDA 해석 결과

## 1. 최종 판단
현재 데이터만으로는 원래 연구 질문인 “수도권과 비수도권 간 삶의 만족도 차이가 고용 여건과 관련되는가”를 검증할 수 없다.

이유는 명확하다.

- 삶의 만족도 원본 `life_satisfaction.csv`가 없다.
- 고용률, 실업률, 경제활동참가율 원자료가 없다.
- 현재 고용 데이터는 2016~2026 전체가 아니라 2025~2026 일부 자료다.
- 2026년은 1~3월 또는 1분기 자료라 연간 비교에 부적절하다.

따라서 현재 자동 결론은 C가 맞다.

> C. 고용 지표만으로는 삶의 만족도 격차를 충분히 설명하기 어렵고, 추가 데이터가 필요하다.

단, 이 결론은 “고용이 중요하지 않다”가 아니라 “현재 데이터로는 검증할 수 없다”는 뜻이다.

## 2. 현재 데이터로 실제 확인 가능한 것
현재 확인 가능한 것은 삶의 만족도가 아니라 고용 구조다. 취업자 수 원자료를 그대로 비교하지 않고, 전체 취업자 대비 비율로 바꾼 변수만 해석했다.

생성된 변수:
- `temporary_worker_ratio`
- `daily_worker_ratio`
- `self_employed_ratio`
- `short_hours_worker_ratio`
- `long_hours_worker_ratio`

생성 불가 변수:
- `employment_rate`
- `unemployment_rate`
- `labor_force_participation_rate`
- `youth_employment_rate`
- `youth_unemployment_rate`
- `male_employment_rate`
- `female_employment_rate`
- `gender_employment_gap`

- 수도권은 청년층 취업자 비중과 임금근로자 비중이 더 높게 관찰된다.
- 비수도권은 고령층 취업자 비중, 단시간 취업자 비중, 자영업자 비율이 더 높게 관찰된다.
- 남녀 취업자 구성비 격차는 비수도권에서 더 크게 관찰된다.
- 장시간 취업자 비중은 수도권/비수도권 차이가 크지 않다.

## 5. 원래 연구 질문별 답변

- 수도권과 비수도권의 삶의 만족도 차이가 실제로 존재하는가?  
  - 현재 답변 불가. 삶의 만족도 데이터가 없다.
- 그 차이는 2016년 이후 확대/축소/유지되는가?  
  - 현재 답변 불가. 삶의 만족도 데이터와 2016~2024 고용 데이터가 없다.
- 고용률, 실업률, 경제활동참가율이 삶의 만족도와 관련되는가?  
  - 현재 답변 불가. 해당 원자료가 없다.
- 청년층 고용, 여성 고용, 종사상지위, 취업시간 등 질적 요소가 더 관련 있는가?  
  - 삶의 만족도와의 관련성은 답변 불가. 다만 고용 구조 차이는 관찰된다.
- 수도권/비수도권보다 실제 고용 여건이 더 잘 설명하는가?  
  - 현재 답변 불가. target과 핵심 고용률 변수가 없어 비교 모델을 만들 수 없다.
- 삶의 만족도와 상대적으로 관련성이 큰 변수는 무엇인가?  
  - 현재 답변 불가. 상관분석과 모델링은 target 부재로 실행하지 않았다.
