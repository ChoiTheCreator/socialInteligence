# 고용 파트 발표자료 Design.md

이 문서는 `employment_wage/presentation` 폴더에서 Codex와 협업할 때 따라야 하는 발표자료 설계 기준이다. 단순한 디자인 메모가 아니라, 고용 파트의 논리, 데이터 근거, 슬라이드 UI 원칙, Figma Plugin API 구현 규칙을 함께 정의한다.

## 발표의 한 문장 결론

2016~2025년 KOSIS 고용 데이터를 기준으로 보면, 지역 간 고용격차는 단순한 고용률 차이가 아니라 고학력 인력이 머무를 수 있는 지역 산업 기반, 청년 정착 가능성, 안정적 임금일자리 구조에서 크게 발생한다.

최종 정책 제안은 `고학력·청년정착형 안정일자리 패키지`다.

## 반드시 유지할 논리 흐름

1. 표면 지표로는 격차가 작아 보인다.
   - 2025년 15~64세 고용률: 수도권 70.2%, 비수도권 69.5%
   - 차이: 0.7%p

2. 구조 지표로 보면 격차가 다시 커진다.
   - 2025년 고용 포용성 종합점수: 수도권 61.9, 비수도권 52.4
   - 차이: 9.5점

3. 격차의 핵심은 일자리 수가 아니라 일자리 구조다.
   - 임금근로자 비중 격차: 7.8%p
   - 상용근로자 비중 격차: 7.3%p
   - 대졸이상 취업자 비중 격차: 6.5%p
   - 청년층 취업자 비중 격차: 2.3%p
   - 고령층 취업자 비중 격차: 6.0%p

4. 정책 우선순위는 데이터로 산정한다.
   - 기준 1: 2025년 고용 포용성 상위 5개 지역과 하위 5개 지역의 레버 점수 격차
   - 기준 2: 2016~2025년 동안 반복적으로 유지된 평균 격차
   - 기준 3: 해당 레버 점수와 종합 고용 포용성 점수의 상관

5. 최종 우선순위는 다음 순서다.
   - 1순위: 고학력·지역산업 일자리 기반, 우선순위 지수 34.2, 상관 0.85
   - 2순위: 청년 정착 일자리, 우선순위 지수 21.3
   - 3순위: 안정적 임금일자리, 우선순위 지수 18.0

6. 따라서 정책 제안은 단순 일자리 수 확대가 아니다.
   - 지역 전략산업과 전문직무 창출
   - 지역 대학-기업 채용 경로
   - 청년 주거·생활 지원
   - 상용직 기반과 사회보험
   - 지역 중소기업 임금·복지 격차 완화

## 타이포그래피

Figma Plugin API에서 오류를 줄이기 위해 기본 폰트는 `Inter`만 사용한다.

- 제목: Inter Bold, 40px 내외
- 섹션 라벨: Inter Bold, 16px 내외
- 카드 제목: Inter Bold, 18~24px
- 본문: Inter Medium, 14~18px
- 표/출처: Inter Medium, 10~13px

Apple SD Gothic Neo, ExtraBold, shadow, SVG, 외부 이미지, 복잡한 mask는 기본 사용하지 않는다. 실행 안정성이 우선이다.

## 슬라이드 구성 기준

현재 기준 덱은 10장이다.

1. 분석 메시지
   - 핵심 질문과 최종 결론의 방향을 제시한다.
   - 반드시 0.7%p, 9.5점, 34.2를 첫 장에 보여준다.

2. 데이터 신뢰성
   - KOSIS, 2016~2025 완전연도, 17개 시도, 6개 raw CSV를 보여준다.
   - `raw_eda_diagnosis.csv`의 결측률, 분기 수, 지역 수를 표로 보여준다.

3. 분석 프레임워크
   - `analysis_framework.csv`의 6개 proxy 차원을 카드로 보여준다.
   - 단순 고용률 분석이 아니라 삶의 질 proxy 설계라는 점을 강조한다.

4. EDA 추세
   - 2016~2025 수도권/비수도권 고용률 추세와 2025 지역 간 range를 함께 보여준다.
   - "고용률 차이는 제한적이지만 일자리 질 지표는 크다"는 전환을 만든다.

5. 표면 지표의 함정
   - 수도권 70.2%, 비수도권 69.5%, 차이 0.7%p를 크게 보여준다.

6. 구조 지표 반전
   - 고용 포용성 9.5점 격차와 임금근로·상용근로·대졸이상·청년/고령 구조 격차를 막대그래프로 보여준다.

7. 정책 우선순위 산정
   - 2025 상하위 격차 + 10년 평균 격차 x 종합점수 상관 = 정책 우선순위 지수 구조를 보여준다.
   - `priority.csv`의 상위 3개 레버를 표와 막대그래프로 보여준다.

8. 지역별 구조 진단
   - `region_recommendations.csv` 기반 heatmap을 보여준다.
   - 청년 정착, 산업 기반, 여성 고용, 기초 접근성 등 지역별 1순위 처방을 요약한다.

9. 정책 패키지
   - 고학력·지역산업 기반 + 청년 정착 + 안정적 임금일자리 3축을 보여준다.

10. 결론과 한계
   - 결론과 한계를 같이 제시한다.
   - 인과분석이 아니라 정책 우선순위 가설이라는 점을 분명히 한다.

## Figma Plugin API 구현 원칙

이 폴더의 자동 생성 코드는 `create_employment_figma_slides.js`를 기준으로 한다.

안정성을 위해 기본적으로 다음 노드만 사용한다.

- `figma.createFrame()`
- `figma.createText()`
- `figma.createRectangle()`
- `figma.createEllipse()`

기본 금지 또는 지양 항목:

- 외부 이미지 의존
- SVG 대량 삽입
- mask/clip을 복잡하게 중첩
- 회전된 선분 다량 생성
- shadow/effect 남발
- 폰트 fallback 없이 Apple SD Gothic Neo 강제
- 텍스트를 이미지로 flatten

반드시 지킬 것:

- 모든 텍스트는 수정 가능한 TextNode여야 한다.
- 모든 그래프는 도형과 텍스트로 재구성한다.
- 슬라이드 이름은 `Employment Report Deck / Slide 01 - ...` 형식으로 명확히 한다.
- 새 슬라이드는 기존 작업물을 덮어쓰지 말고 현재 페이지 하단에 생성한다.
- 생성 후 `figma.viewport.scrollAndZoomIntoView(frames)`를 호출한다.
- 수정 후 `node --check employment_wage/presentation/create_employment_figma_slides.js`를 실행한다.

## 레이아웃 규칙

- 장표마다 같은 카드 3개 패턴을 반복하지 않는다.
- 보고서형 발표자료처럼 표, 막대그래프, heatmap, 산식, 메트릭 카드, 결론 카드가 섞여야 한다.
- 텍스트가 하단 바와 겹치지 않도록 본문 영역은 y=400 이전에 끝내는 것을 기본으로 한다.
- 하단 파란 바는 결론 강조용으로만 사용한다.
- 출처는 슬라이드 하단 또는 작은 주석으로 넣는다.
- 데이터 숫자는 장식보다 우선한다.
- 모든 숫자는 보고서/CSV와 일치해야 한다.

## 발표자가 말할 핵심 문장

- "고용률만 보면 수도권과 비수도권의 차이는 0.7%p 수준입니다."
- "하지만 고용 포용성 종합점수로 보면 격차는 9.5점까지 벌어집니다."
- "즉 문제는 일자리 수보다 지역 안에 어떤 질의 일자리와 커리어 경로가 있는지입니다."
- "우선순위 지수 기준으로 가장 큰 정책 레버는 고학력·지역산업 일자리 기반입니다."
- "따라서 단순 일자리 수 확대가 아니라 고학력·청년정착형 안정일자리 패키지가 필요합니다."

## 수정 전 체크리스트

발표자료를 다시 생성하거나 수정하기 전에 확인한다.

- 결론이 `고학력·청년정착형 안정일자리 패키지`로 닫히는가?
- 0.7%p와 9.5점의 대비가 명확한가?
- 정책 우선순위 1, 2, 3위가 정확한가?
- 데이터 신뢰성 슬라이드가 들어가 있는가?
- 지역별 처방이 전국 단일 정책처럼 보이지 않는가?
- 한계가 빠지지 않았는가?
- 텍스트/도형이 1280 x 720 프레임 밖으로 나가지 않는가?
- 하단 바가 본문을 덮지 않는가?
- `node --check`가 통과했는가?
